Student Grade Tracker

Project Description

Student Grade Tracker is a Java Swing-based desktop application designed to manage student records and track their academic performance. It allows users to add, edit, delete, and search student details, calculate grades, and generate performance statistics.

Features

- Add student details (Name and Marks).
- Edit existing student records.
- Delete selected student records.
- Search students by name.
- Automatically calculate grades.
- Display Pass/Fail status.
- Calculate average, highest, and lowest marks.
- Display total students and topper details.
- Export student records to CSV format.
- Clear all student records.

Technologies Used

- Java
- Java Swing
- AWT
- JTable
- Eclipse IDE

Grade Calculation

Marks| Grade
90–100| A+
80–89| A
70–79| B
60–69| C
35–59| D
Below 35| F

How to Run the Project

1. Install Java JDK.
2. Open Eclipse IDE.
3. Create or import a Java project.
4. Create a class named "StudentGradeTracker".
5. Paste the source code.
6. Run the program.

Output

The application displays a dashboard containing student statistics and a table of student records.
